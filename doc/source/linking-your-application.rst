Linking Your Application with Intel® Cryptography Primitives Library
====================================================================


This section discusses linking options available in Intel® Cryptography Primitives Library.


The Intel® Cryptography Primitives Library supports the following linking
options:


-  Single-threaded dynamic
-  Single-threaded static
