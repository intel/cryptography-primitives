Support Functions and Classes
=============================


This appendix contains miscellaneous information on support functions
and classes that may be helpful to users of the Intel® Cryptography Primitives Library.


The :ref:`Version Information Function <version-information-function>` section
describes an Intel® Cryptography Primitives Library function that provides version
information for cryptography software.


The :ref:`Classes and Functions Used in
Examples <classes-and-functions-used-in-examples>` section
presents source code of classes and functions needed for examples given
in the document sections.
