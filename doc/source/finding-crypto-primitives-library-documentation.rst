Finding the Intel® Cryptography Primitives Library Documentation
================================================================


The :file:`{<install-dir>}/share/doc/ippcp` directory, set up during
installation, includes a lot of helpful documentation related to
Intel® Cryptography Primitives Library. See the :file:`get_started.htm` file for a
listing of all the
available documents with links or pointers to their locations.


A PDF version of this document may be downloaded using the Download
button in the upper right corner. To download all of the Intel® Integrated
Performance Primitives and
Intel® Cryptography Primitives Library documentation, see Downloadable `Documentation: Intel® oneAPI Toolkits and
Components <https://www.intel.com/content/www/us/en/developer/articles/guide/download-documentation-intel-oneapi-toolkits-components.html>`__
