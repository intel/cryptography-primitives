.. _mbx-support-functions:

Multi-buffer library support functions
======================================

This section contains information on support functions that may be helpful to users
of the Intel® Crypto Multi-buffer Library.

The :ref:`mbx_get_algo_info<mbx-get-algo-info>` outputs the number of parallel buffers
supported for the specified algorithm and can be used to check if the algorithm is enabled for the
current CPU.
